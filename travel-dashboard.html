Travel Dashboard • POC 01

Know Maui + your current location in one glance.

This dashboard shows the Maui home base and wherever you are right now. It updates time zones, pulls weather from OpenWeatherMap, and relies on browser geolocation.

What this POC does

  • Live time for Maui (Pacific/Honolulu timezone).
  • Local time based on your device location.
  • Weather summaries with a replaceable API key.
